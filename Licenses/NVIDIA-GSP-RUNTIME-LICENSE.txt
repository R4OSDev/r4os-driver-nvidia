NVIDIA GSP boot/runtime source notices
=====================================

Complete source notices for the linked GSP queue, event, sequencer,
core and teardown adapters. NVIDIA sources are pinned to 570.144;
Nouveau reference provenance is recorded in THIRD_PARTY_NOTICES.md
and the ExFiles/Reference/GFX/Nvidia archives. Original R4OS
ownership/lifetime code remains Apache-2.0. Firmware binaries keep
their separately packaged licenses. No notice below is replaced.
